# ✈️ Sistema de Gerenciamento de Voos e Passagens em C

Este repositório contém um sistema desenvolvido em **Linguagem C** que simula um aplicativo de consulta e gerenciamento de voos, permitindo visualizar voos disponíveis, consultar passagens e realizar reservas.

## 📌 Sobre o Projeto
O objetivo deste software é aplicar conceitos fundamentais de programação estruturada em C — como estruturas (`structs`), ponteiros, manipulação de dados e lógica de fluxo — para criar um sistema funcional de reservas de passagens aéreas operado via terminal.

---

## 📁 Estrutura do Repositório
* **`main.c`**: Código-fonte principal contendo a função `main`, o loop do menu interativo e a lógica de navegação.
* **`voos.c` / `voos.h`** *(Opcional)*: Arquivos de implementação das funções de cadastro, busca e listagem de voos.
* **`README.md`**: Documentação oficial do projeto.

---

## 🚀 Funcionalidades
* **Listagem de Voos:** Exibe todos os voos disponíveis com detalhes como origem, destino, horários e assentos vagos.
* **Consulta de Passagens:** Permite buscar informações detalhadas sobre bilhetes específicos.
* **Reserva de Assentos:** Simula o processo de compra ou reserva de passagens para um determinado voo.
* **Menu Interativo:** Interface amigável em modo texto para facilitar a navegação do usuário.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem C** (Padrão C99 ou superior)
* **Compilador compatível** (GCC, Clang ou MinGW)
